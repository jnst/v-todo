# v-todo

## 技術スタック

- **Next.js** (v15)
- **React** (v19)
- **TypeScript**
- **Tailwind CSS**
- **Radix UI**
- **lucide-react**（アイコン）
- **class-variance-authority, clsx**（ユーティリティ）

## 概要

このプロジェクトは、Next.jsとTypeScriptを用いたシンプルなTodoアプリです。Tailwind CSSによるスタイリングと、Radix UIコンポーネントを活用しています。

## 起動方法

1. 依存パッケージのインストール

```bash
npm install
```

2. 開発サーバーの起動

```bash
npm run dev
```

3. ブラウザで `http://localhost:3000` にアクセス

## ビルド

```bash
npm run build
```

## 本番サーバー起動

```bash
npm start
```

---

- スタイルやUIはTailwind CSSとRadix UIでカスタマイズ可能です。
- 詳細な設定は `tailwind.config.js` や `tsconfig.json` を参照してください。
